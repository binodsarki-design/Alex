 # School Website

A responsive school homepage published with GitHub Pages.

**Live website:** https://binodsarki-design.github.io/Alex/

## Website features

- School information and contact details
- School photo and notices
- Responsive layout for mobile and desktop

## Updating the website

Edit the school details locally, then run `build-github-pages.ps1`. Upload the updated files from the `github-pages` folder to this repository and commit them.

The GitHub Pages contact form is display-only. Do not publish private student information or marks.
